## Aplicación

El tutorial tendrá orientación segura, práctica de profundidad/salto, encuentro de pico y una combinación ambiental breve. La cantidad de cámaras se decide en Plan_Nivel1 tras las métricas. No se toma una sala del atlas como plantilla; los objetivos mineros y las anclas narrativas determinan la geometría. Las tres ilustraciones previas solo orientan el aspecto.
